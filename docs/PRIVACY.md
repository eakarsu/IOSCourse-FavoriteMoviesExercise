# Privacy disclosure

Favorite Movies is local-only. It has no account, network request, advertising, tracking, analytics, crash-reporting SDK, or remote database. Movie text and an optional image selected by the user remain in the app's Core Data store inside its container. The photo picker is used only to select the optional poster; the app does not upload it.

Users can delete individual movies with the table's standard swipe-to-delete action. Uninstalling removes the remaining app container. The checked-in privacy manifest declares no tracking or collected-data categories. Reassess the manifest, retention behavior, and App Store answers before adding any provider or SDK.
